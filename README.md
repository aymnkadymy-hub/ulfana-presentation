# أولفانا — تجربتك التعليمية، بيدك

عرض عربي تفاعلي من 11 شريحة يحافظ على نص المالك حرفيًا في 25 فقرة. يبدأ بالتحكم في التجربة، ثم سبب بناء أولفانا وتصميمها، وتقنية الاسترجاع والمكتبة، ثم النتائج والخاتمة والتواصل. الشعار والشخصيات من المنصة الأصلية، مع لقطتين فعليتين للـFeed والمكتبة يمكن تكبيرهما ومخططات توضيحية تفاعلية.

[افتح العرض](https://aymnkadymy-hub.github.io/ulfana-presentation/)

التنقّل: الأزرار، السهم الأيسر للتالي والأيمن للسابق، PageDown / PageUp، أو السحب على الهاتف. الفهرس وملء الشاشة في الأعلى. يمكن إيقاف الحركة، وتُحترم إعدادات تقليل الحركة. دون JavaScript تظهر الشرائح بالتمرير. الطباعة تعرض الشرائح الإحدى عشرة. على الشاشات الصغيرة جدًا يمكن تمرير محتوى الشريحة للحفاظ على النص كاملًا بحجم مقروء.

```sh
python3 -m http.server 8088 --bind 127.0.0.1
```

ثم افتح `http://127.0.0.1:8088/`.

```sh
python3 scripts/build_site.py
node --check slides.js
node --check companions.js
python3 scripts/check_public.py
```

ينفّذ GitHub Actions الأوامر أعلاه. أما نسخة PDF فتُحدَّث يدويًا بعد أي تعديل على الشرائح،
لأن توليدها يحتاج متصفحًا ولا يعمل ضمن النشر:

```sh
python3 scripts/build_site.py && python3 scripts/build_pdf.py
```

ينشر GitHub Actions الحزمة `_site` عند تحديث `main`. يبقى `/investor/` تحويلًا للرابط الجديد حفاظًا على الروابط السابقة؛ الاسم العام للعرض لا يتضمن مستثمرين.

أُزيل زر «المصادر» بطلب المالك؛ يبقى زر «شاهد مثال المحادثة» في شريحة تقنية الاسترجاع، ويعرض مثالًا واحدًا من محادثة فعلية. ملفات القياس الكاملة باقية في `data/`. مخطط شريحة النتائج يقيس **ترتيب المصدر الأول** في اختبار محفوظ، لا دقة الإجابات. حُذفت بطلب المالك شريحة مقارنة جودة الأجوبة، ثم شريحتا «مصممة حول احتياجاتك» و«خلف التجربة»، وتبقى المراجعة الكاملة في المصادر. نتائج المحادثات والدرجات لكل حالة متاحة في المصادر. لا تُنشر ملفات الكتب أو الأسئلة الأصلية الكاملة أو بيانات حسابات الاختبار.
