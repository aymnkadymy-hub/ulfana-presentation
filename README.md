# أولفانا — تعلّمك يبدأ بك

عرض عربي تفاعلي من 10 شرائح: السبب، تجربة المستخدم، ثم المنتج. الشعار والشخصيات من المنصة الأصلية، ورسوم الواجهات أمثلة توضيحية مبسّطة.

[افتح العرض](https://aymnkadymy-hub.github.io/ulfana-presentation/)

التنقّل: الأزرار، السهم الأيسر للتالي والأيمن للسابق، PageDown / PageUp، أو السحب على الهاتف. الفهرس وملء الشاشة في الأعلى. يمكن إيقاف الحركة، وتُحترم إعدادات تقليل الحركة. دون JavaScript تظهر الشرائح بالتمرير. الطباعة تعرض الشرائح العشر.

```sh
python3 -m http.server 8088 --bind 127.0.0.1
```

ثم افتح `http://127.0.0.1:8088/`.

```sh
python3 scripts/build_site.py
node --check slides.js
python3 scripts/check_public.py
```

ينشر GitHub Actions الحزمة `_site` عند تحديث `main`. يبقى `/investor/` تحويلًا للرابط الجديد حفاظًا على الروابط السابقة؛ الاسم العام للعرض لا يتضمن مستثمرين.

المصادر والمنهجية والنتائج الكاملة في نافذة «المصادر». مخطط الشريحة الخامسة يقيس **ترتيب المصدر الأول** في اختبار تاريخي، لا دقة الإجابات. الاختبار الموسّع يقارن النموذج المجرد بمسار المكتبة الحي الكامل. لا تُنشر ملفات الكتب أو الأسئلة الأصلية الكاملة أو بيانات حسابات الاختبار.
