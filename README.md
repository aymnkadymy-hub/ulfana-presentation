# أولفانا — تجربتك التعليمية، بيدك

عرض عربي تفاعلي من 13 شريحة يحافظ على النص المقدم حرفيًا في 30 فقرة. يبدأ بالتحكم في التجربة، ثم سبب بناء أولفانا وتصميمها، وتقنية RAG والمكتبة، ثم النتائج والخاتمة والتواصل. الشعار والشخصيات من المنصة الأصلية، مع لقطتين فعليتين للـFeed والمكتبة يمكن تكبيرهما ومخططات توضيحية تفاعلية.

[افتح العرض](https://aymnkadymy-hub.github.io/ulfana-presentation/)

التنقّل: الأزرار، السهم الأيسر للتالي والأيمن للسابق، PageDown / PageUp، أو السحب على الهاتف. الفهرس وملء الشاشة في الأعلى. يمكن إيقاف الحركة، وتُحترم إعدادات تقليل الحركة. دون JavaScript تظهر الشرائح بالتمرير. الطباعة تعرض الشرائح الثلاث عشرة. على الشاشات الصغيرة جدًا يمكن تمرير محتوى الشريحة للحفاظ على النص كاملًا بحجم مقروء.

```sh
python3 -m http.server 8088 --bind 127.0.0.1
```

ثم افتح `http://127.0.0.1:8088/`.

```sh
python3 scripts/build_site.py
node --check slides.js
python3 scripts/check_public.py
```

ينشر GitHub Actions الحزمة `_site` عند تحديث `main`. يبقى `/investor/` تحويلًا للرابط الجديد حفاظًا على الروابط السابقة؛ الاسم العام للعرض لا يتضمن مستثمرين.

المصادر والمنهجية والنتائج الكاملة في نافذة «المصادر». مخطط الشريحة 11 يقيس **ترتيب المصدر الأول** في اختبار تاريخي، لا دقة الإجابات. حُذفت شريحة مقارنة جودة الأجوبة بطلب المالك، وتبقى المراجعة الكاملة في المصادر. بُدّل موضعا الشريحتين 5 و7 دون تعديل نصهما. نتائج المحادثات والدرجات لكل حالة متاحة في المصادر. لا تُنشر ملفات الكتب أو الأسئلة الأصلية الكاملة أو بيانات حسابات الاختبار.
