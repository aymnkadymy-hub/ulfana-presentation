# أولفانا — مساحة تكبر معك

عرض عربي تفاعلي للمنصة، والمكتبة الناطقة، والرفيق الدراسي، ونتائج تقييم Gemma 3 4B.

**افتح العرض:** https://aymnkadymy-hub.github.io/ulfana-presentation/

## تشغيل محلي

```sh
python3 -m http.server 8088
```

افتح http://localhost:8088/ . يحتاج تحميل بيانات المقارنة والمؤشرات إلى خادم HTTP؛ لا تستخدم file://.

## المحتوى

- محاكاة تعليمية معلّمة بوضوح، تبويبات للمنصة، لقطات قابلة للتكبير وشخصيات SVG أصلية.
- `data/evaluation.json`: قياس استطلاعي، بحجم العينة والمنهج والحدود؛ لا يمثل كل استخدامات المنصة.
- `data/methodology.md`: المنهجية وشرح النتائج.
- `data/kpis.json`: تعريفات مؤشرات الأداء المستقبلية. القيم غير المقاسة ليست صفرًا، ولا يدّعي العرض اتصالًا ببيانات استخدام حية.
- خطوط عربية محلية مع تراخيصها في `assets/fonts/`.

## النشر

تُنشئ `python3 scripts/build_site.py` مجلد `_site/` بقائمة محددة من الملفات العامة فقط. يتحقق `python3 scripts/check_public.py` من الأصول وبيانات القياس وعدم وجود أسرار ظاهرة. GitHub Actions ينفذ التحقق وينشر المجلد عند الدفع إلى main. المسار القديم `/investor/` يحوّل إلى العرض الجديد. الملفات القديمة محفوظة في تاريخ المشروع وبعض المجلدات القديمة لكنها ليست جزءًا من حزمة الموقع الجديدة.

لا تضع قواعد بيانات التطبيق، بيانات مستخدمين، ملفات بيئة، رموز دخول أو النتائج الخام الخاصة في هذا المستودع. لقطات العرض مأخوذة من حساب العرض دون منشورات مستخدمين.

زر المنصة المحلية يتطلب تشغيل أولفانا على جهاز الزائر نفسه عند المنفذ 8000؛ الرابط المنشور يعرض العرض التقديمي، ولا يستضيف خادم المنصة أو النموذج.
